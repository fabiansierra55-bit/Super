# SuperLotto lifecycle recovery — 2026-08-02

The production lifecycle is current through the verified August 1 draw, and a 60-line bundle is locked for August 5. Lottery outcomes remain random; this recovery changes audit continuity, not the underlying odds of any individual ticket.

## Cause

GitHub required manual workflow approval for pull requests created by `github-actions[bot]` under the repository's first-time-contributor policy. The required pull-request `ci` check therefore never started, even though the workflow-dispatch CI on the artifact branch passed. Protected `main` remained at commit `542e5df18cba4ab61f62fba602c80ed75dafa637`.

Later scheduled runs continued to verify official results correctly, but stopped with `latest result skips one or more cycle dates; refusing to create an after-the-draw prediction`. That was the intended fail-closed behavior.
